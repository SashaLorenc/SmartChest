# Changelog

## 1.0.0

First release.

- Categories on chests, chosen in game, several per chest.
- 16 default item categories, custom categories, per-item editing (K key).
- Store by category (L key or inventory button), Store here, Sort.
- Catch-all chest, chest priorities, full chest warning.
- Item search: matching chests glow and show the quantity.
- Integrations: Quick Stack Store Sort Trash Restock, AzuAutoStore, Multi User Chest, Dynamic Storage Piles, inventory and backpack mods.
- English and French.
